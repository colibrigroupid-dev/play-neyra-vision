## 2. Kinodaran изнутри (из JS-сборки и сетевых запросов)

- **Фронт:** React (Create React App, `static/js/main.*.js` + чанки), i18n через `locales/ru|en/translation.json?v=1.3.87`, маршруты: `/about /faq /term /privacy /device /link/auth /link/media /pay/:sessionId /pay/:sessionId/result /round /blocked /unsubscribe /404`. Каталог и плеер — SPA без отдельных URL в бандле (стейт).
- **Бэкенд:** REST `https://devapi.kinodaran.com/api/v1/` (в проде — свой домен), методы `authGuest` (гостевой токен — поэтому бесплатное смотрят без регистрации), `authWeb`, `authWebRefresh`, `register`, `history`, `continueWatching`, `search`, `media`, `media_detail_banner_config` (Firebase Remote Config). Логин через Google, Facebook, Apple; на ТВ — `/device` + `/link/auth` (вводишь код с телевизора на сайте).
- **Видео:** video.js + VHS (HLS, `application/x-mpegURL`, `m3u8`), есть и DASH `.mpd`; **DRM**: `keySystems` → Widevine (Chrome/Android), FairPlay (Safari/iOS), PlayReady (Edge/ТВ) — т.е. плеер видеoјs-contrib-eme. Субтитры WebVTT (vtt.js). Реклама — Google IMA3 (`imasdk`) + AdSense на бесплатном уровне.
- **Платежи:** Stripe (карты) и **Idram** (армянский кошелёк) — локальный способ оплаты обязателен; `/pay/:sessionId` — платёжная сессия с результатом. Бандл с оператором: подписка активируется по номеру телефона.
- **Служебное:** Firebase (аналитика, remote config, инсталляции), Sentry (ошибки), reCAPTCHA Enterprise, Facebook Pixel, Google Ads конверсии, feedback.one (виджет обратной связи).
- **Дизайн:** Roboto, тёмно-синий `#020a17`, жёлтый акцент (кнопки), hero с текстом слева и коллажем постеров 2:3 справа; широкий баннер 15:1.
- **Чего у них нет:** отдельных URL тайтлов (SEO страдает), серверного рендера, открытого каталога в HTML — всё за JS.

## 3. Как работает стриминг внутри (конвейер)

1. **Мастер** → **транскодирование в лестницу** качеств (например 1080p 5 Мбит, 720p 2,8, 480p 1,4, 360p 0,8; H.264 как база, HEVC/AV1 — экономия 30–50 % трафика, но не везде играет).
2. **Упаковка в HLS** (и/или DASH; CMAF = один набор сегментов на оба): `master.m3u8` → по качеству `index.m3u8` → сегменты по 4–6 с. Мы собрали такую лестницу из тизера «Степной код» одной командой ffmpeg (`media/stepnoy-kod/hls/`): 720p + 360p, сегменты 4 с, 50 МБ на 99 с.
3. **Хранение + CDN:** сегменты лежат в объектном хранилище/на сервере, CDN кэширует у зрителя. Для VOD кэш почти идеален.
4. **Плеер:** hls.js (Chrome/Firefox/Android), нативный HLS в Safari/iOS; ABR сам выбирает качество по каналу. Shaka/video.js/Plyr — обёртки.
5. **Доступ:** подписанные ссылки (токен + срок) → ссылку нельзя переслать; **DRM** (Widevine/FairPlay/PlayReady) — ключи выдаёт лицензионный сервер только после проверки прав; нужен для чужого лицензионного контента, для своих тизеров и сериала — избыточен на старте.
6. **Аккаунты и права:** кто, что, в какой стране, сколько устройств; «продолжить просмотр» = позиция на сервере; биллинг отдельно от видео.
7. **Аналитика качества:** время старта, буферизации, ошибки (Mux Data, Sentry, свой лог).

## 4. Где хранить и раздавать видео — цены (официальные страницы, 13.10.2026)

| Вариант | Цена | Что даёт | Минусы |
|---|---|---|---|
| **Свой сервер (Хельсинки 212.192.8.91, уже есть)** | 0 ₽ сверх аренды | nginx раздаёт `.m3u8/.ts` как файлы; уже так крутим видео Школы (≈80 Мбит/с ≈ 40–50 зрителей 720p) | один сервер, нет CDN, при 100+ зрителях одновременно упрётся; HLS резать самим (ffmpeg) |
| **Bunny Stream** | хранение от $0,01/ГБ, доставка от $0,005/ГБ, кодирование и плеер бесплатно, минимум $1/мес; пример с их страницы: 300 ГБ + 50 ГБ трафика ≈ $4,5/мес | CDN по миру (можно отключать регионы), токен-защита ссылок, DRM-опции, MP4 fallback | консоль «для технарей»; оплата картой/PayPal |
| **Cloudflare Stream** | $5 за 1000 мин хранения/мес + $1 за 1000 мин просмотра; кодирование бесплатно, файл до 30 ГБ | проще всех, свой плеер, HLS/DASH, подписанные URL, у нас уже Cloudflare DNS | дороже при росте: 500 000 мин просмотра = $500 + хранение |
| **Mux** | кодирование 1080p бесплатно, хранение $0,003/мин/мес, доставка $0,001/мин **после 100 000 бесплатных минут в месяц**, $20 кредита | лучшая аналитика, подписанные URL включены | DRM только через продажи; дороже Bunny при больших объёмах |

Ориентир для нас: библиотека 10 часов (600 мин ≈ 25 ГБ в лестнице) и 20 000 просмотров-минут в месяц → Bunny ≈ $1–2, Cloudflare ≈ $3 + $20, Mux ≈ $2 (в бесплатных минутах). На старте разница копеечная; решает удобство и защита ссылок.

## 5. Рынок Казахстана (для позиционирования)

- Кинопоиск — 53 % всех подписчиков онлайн-кинотеатров и 56 % платных (K Research Central Asia); доступ через Яндекс Плюс; эксклюзивы казахстанских фильмов, в 2024 Минкультуры добавило 17 казахстанских фильмов.
- Рынок онлайн-видео 2025: 27,65 млрд ₸ (+49 %), 59 % — платная подписка. У 42 % горожан есть хотя бы одна подписка (II кв. 2026).
- Другие: Amediateka (HBO), MEGOGO (1 499 / 1 999 ₸ по недатированному рейтингу), ivi (с Alash Media Group), Okko, **kino körü** (Halyk + alma PLUS, 9 кинозалов, 80 000 фильмов, телеканалы), Wildberries готовит свой кинотеатр (12.2025). 60 % молодёжи смотрят на бесплатных сайтах.
